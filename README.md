# Exam Application

A simple exam management application built with ASP.NET Core and Angular.

## Features

* View exam questions
* Add new exam questions
* Delete exam questions
* Dynamic question and choice data from the backend API
* Automatic question numbering
* Clean green-themed UI

## Technologies

### Backend

* ASP.NET Core
* C#
* REST API
* SQLite

### Frontend

* Angular
* TypeScript
* HTML
* CSS
* Angular Router
* HttpClient

## Frontend Setup

Navigate to the frontend project:

```bash
cd ExamFrontend
```

Install dependencies:

```bash
npm install
```

Start the Angular development server:

```bash
npx ng serve
```

The application will be available at:

```text
http://localhost:4200
```

## Backend Setup

Start the ASP.NET Core backend project before using the frontend.

The Angular development server uses `proxy.conf.json` to forward `/api` requests to the backend.

Example:

```text
Angular
http://localhost:4200/api/questions
        │
        ▼
ASP.NET Core API
/api/questions
```

## API Endpoints

| Method | Endpoint              | Description           |
| ------ | --------------------- | --------------------- |
| GET    | `/api/questions`      | Get all questions     |
| GET    | `/api/questions/{id}` | Get a question by ID  |
| POST   | `/api/questions`      | Create a new question |
| DELETE | `/api/questions/{id}` | Delete a question     |

### Create Question

Request:

```json
{
  "questionText": "ภาษาโปรแกรมใดใช้พัฒนาแอปพลิเคชันบนแพลตฟอร์ม .NET ได้?",
  "choices": [
    "C#",
    "Java",
    "Python",
    "PHP"
  ]
}
```

The question number is generated by the backend.

## Application Pages

### IT 08-1

Question list page.

* Displays questions received from the backend
* Displays four choices for each question
* Allows adding a new question
* Allows deleting an existing question

### IT 08-2

Question creation page.

* Enter question text
* Enter four answer choices
* Save the question
* Cancel and return to the question list

## Notes

The frontend communicates with the backend through REST API endpoints. Question data is not hardcoded in the Angular application.
